
# 📝 Blog Website Platform

A full-featured blog web application where users can **read, write, and interact with blog posts** in a modern and intuitive environment.

---

## 🚀 Features

### ✍️ Writing & Publishing

* Create and publish blog posts easily
* Rich **text editor with styling tools** (bold, italic, headings, lists, etc.)
* Add categories and tags to organize content

### 📖 Reading Experience

* Browse blogs by **categories**
* Clean and responsive UI for smooth reading
* Search and filter posts

### 💬 Engagement

* Like posts ❤️
* Comment on blogs 💬
* Save/bookmark posts for later 🔖

### 👤 User Features

* User authentication (Login / Signup)
* Personal dashboard
* View your own posts and saved blogs

---

## 🛠️ Tech Stack

**Frontend**

* React.js / Next.js
* Tailwind CSS

**Backend**

* Node.js + Express

**Database**

* MongoDB

**Other Tools**

* JWT Authentication
* Rich Text Editor (e.g., Quill / TipTap)

---

## 📂 Project Structure

```
blog-website/
```

## ⚙️ Installation & Setup

### 1️⃣ Clone the repository

```bash
git clone https://github.com/your-username/blog-website.git
cd blog-website
```

### 2️⃣ Install dependencies

```bash
# frontend
cd client
npm install

# backend
cd ../server
npm install
```

### 3️⃣ Run the project

```bash
# backend
npm run dev

# frontend
npm start
```
